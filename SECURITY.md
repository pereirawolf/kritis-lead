# Sicherheit: Schwachstellen melden

KRITIS-LEAD ist ein privates Forschungsvorhaben ohne Betriebsorganisation. Meldungen werden nach bestem Vermögen bearbeitet; eine Frist wird nicht zugesagt.

Schwachstellen bitte **nicht** als öffentliches Issue melden, sondern vertraulich über GitHub: **[Schwachstelle melden](https://github.com/pereirawolf/kritis-lead/security/advisories/new)** (Reiter „Security“ → „Report a vulnerability“).

Hilfreich sind: betroffener Commit, Schritte zum Nachstellen, erwartete und tatsächliche Wirkung. Bitte keine echten Betriebs-, personenbezogenen oder eingestuften Daten mitsenden.
