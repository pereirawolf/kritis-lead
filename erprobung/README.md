# Erprobungsunterlagen

Unterlagen für das Planspiel Orkantief „Ilka“ im Landkreis Sonneberg. Rahmen, Fragestellungen und Erfolgskriterien: [docs/ERPROBUNG.md](../docs/ERPROBUNG.md). Alle Inhalte sind fiktiv.

| Datei | Für | Inhalt |
|---|---|---|
| [DREHBUCH.md](DREHBUCH.md) | alle | Lage, Rollen, Ablauf mit Spiel- und Realzeit, Aufgaben der Lagezentren |
| [plan-vorlage.md](plan-vorlage.md) | Spielleitung | Erprobungsplan, vor Beginn auszufüllen |
| [spielleitung/ANLEITUNG.md](spielleitung/ANLEITUNG.md) | Spielleitung | Vorbereitung, Sammeln und Prüfen der Dateien, Meldungssatz, Messung |
| [spielleitung/loesungen.md](spielleitung/loesungen.md) | Spielleitung | Musterlösungen und Lösung des Bogens Herkunft (erst nach Abgabe zeigen) |
| [einspielungen/](einspielungen/README.md) | Betreiber | 12 Lagekarten, je Betreibermeldung eine |
| [boegen/selbstprotokoll.md](boegen/selbstprotokoll.md) | Betreiber | Zeit und erster Export je Meldung |
| [boegen/herkunft-stichprobe.md](boegen/herkunft-stichprobe.md) | Lagezentren | 20 Angaben zum Zuordnen |
| [boegen/kodiervergleich.md](boegen/kodiervergleich.md) | Lagezentren | Lagenradar zweier Personen |
| [boegen/befragung.md](boegen/befragung.md) | alle | Befragung nach dem Planspiel |
| [boegen/auswertung.md](boegen/auswertung.md) | Spielleitung | Messung je Kriterium |
| [trockenlauf/ergebnis.md](trockenlauf/ergebnis.md) | alle | maschineller Durchlauf ohne Teilnehmende (`npm run trockenlauf`) |
| `ergebnisse/` | alle | Ergebnisse nach der Auswertung, ohne Namen und Rohdaten |

Einspielungen, Bogen Herkunft, Bogen Kodiervergleich und Lösungen erzeugt `npm run bauen` aus dem Szenario und dem Profil; sie werden nicht von Hand bearbeitet. Die Release-Datei `kritis-lead-erprobung-<Version>.zip` enthält diesen Ordner zusammen mit Formular, Anleitung und Profilpaket.
